3. Failure routing inside a handler

This is the part blocking issues 1–3 and should-fix 7–9 change.

runSub throws / returns
        │
        ▼
 1. run signal aborted?           ──yes──▶ return isError ABORTED, emit nothing
        │ no                               (pipeline rethrows StreamAbortedError)
 2. spawn-timeout signal aborted? ──yes──▶ AGENT_TIMEOUT   ─┐   fix #3 separate variable,
        │ no                                                 │   checked before the generic abort
 3. extra.signal aborted?         ──yes──▶ code from B01     │
        │ no                               verdict           │
 4. init-tools mismatch?          ──yes──▶ state.fatal ──────┼──▶ internal controller aborts the orchestrator
        │ no                               fix #9                │
 5. AgentError?                   ──yes──▶ agent_failed (non-final), ┘
        │ no                               state.lastFailure, spentUsd += err.costUsd  fix #5,
        │                                  return isError digest {errorCode}
        │                                  → orchestrator may retry, write without research, or stop
 6. anything else (bug)           ──────▶ state.fatal ──▶ abort orchestrator

In runAgentQuery, the catch now checks the initError flag before it checks signal.aborted fix #1.

4. What the pipeline decides after the orchestrator ends

orchestrator query ended
  │
  ├─ state.fatal set ─────────────────────────▶ error INTERNAL_ERROR    fix #7 checked BEFORE the abort branch
  │
  ├─ run aborted ─────────────────────────────▶ rethrow StreamAbortedError, nothing saved
  │
  ├─ state.draftMd non-empty ─────────────────▶ save + notify + run_completed
  │     (even if the orchestrator hit max turns or budget after the writer succeeded)
  │
  └─ no draft ─ precedence  fix #8:
        1. orchestrator's own AgentError      ─▶ error {orchestrator, code} + agent_failed to close the plan step
        2. state.lastFailure                  ─▶ error {writer|researcher, code, spawn}   e.g. writer / WRITER_EMPTY
        3. otherwise                          ─▶ error NO_DRAFT {orchestrator}

6. Budget over time (max 2.75 USD)

reserved up front: orchestrator 0.25
spawn budget = min(agentCap, 2.75 − 0.25 − spentOnSpawns)
researcher #1 ≤ 1.00 → researcher #2 ≤ 1.00 → writer ≤ 0.50
refused with BUDGET_EXHAUSTED if the remaining budget is under 0.05

With the cost fix fix #5, failed passes count toward spentUsd instead of being lost.
